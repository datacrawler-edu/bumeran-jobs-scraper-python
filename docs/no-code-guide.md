# Run Bumeran job searches without code

1. Open the [hosted Actor](https://apify.com/datascraperes/bumeran-jobs-scraper?fpr=edudata).
2. Select countries, enter a keyword and set Maximum jobs to 3.
3. Keep optional and advanced filters empty unless needed. Review pricing.
4. Click Start. Inspect the Dataset and Run summary.
5. Export JSON, CSV or Excel. Read input warnings before treating a partial search as complete.

Argentina, Mexico, Peru and Venezuela use Bumeran; Chile uses Laborum, Ecuador uses Multitrabajos and Panama uses Konzerta. No account on those job boards is needed.
